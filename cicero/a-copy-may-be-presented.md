# A copy may be presented

**Status: Decided 2026-10-14, Executed 2026-10-14.** The round is [the embedded PDF](https://github.com/egildo/beltype/blob/42b348b547d269a217a7f193042fe216386a4650/.claude/plans/the-embedded-pdf/plan.md) (stage 1); the measurements it stands on are in its `results.md`, stage 0. The title is the executor's proposal, Egildo's to rule. The pins `packages/essay/test/presenters.test.js` were written first and read red before the code.

## Context

Cicero shows the original where it can and a copy where it must: a cut block (the continuation and the constructed first fragment), composed content, a block holding a nested `position: fixed` box, a running element's or a fixed box's per-page copy, and its own measuring copies. A copy is made by `cloneNode`, which copies a tree and nothing that is not in it. Stage 0 measured the consequence: a `<canvas>` drawn by a script is **blank on every page that shows a copy of it** (opaque-pixel sum 0 against 7 650 000 on the original), the box is the right size, and nothing says so. An `<object>` that embeds a PDF has the same problem for a different reason: the page it shows is not in the DOM at all, and a copy that kept the `data` would start the browser's own viewer for every page that holds one (stage 0, part B: three fetches and a viewer frame created and torn down before the first cut).

The first draft of the round put a `<canvas>` inside the source `<object>`, and was overturned by reading the copy code: every copy would have been blank. The mechanism has to act at the copy.

## Decision

**A host registers a presenter, and every copy Cicero makes of a matching element is the presenter's element.** `src/presenters.js` holds the registry: `present(selector, make)`, where `make(source)` returns ONE element, synchronously; `window.__beltypeCicero.present` exposes it beside `run` (`seam/client.js`). The first presenter whose selector matches the source (`source.matches`) wins. The hook is general: any replaced element whose content is not in the DOM (a live canvas, later a rendered diagram) has the same problem, and nothing in `src/` knows what a PDF is.

**The seat is `word-space.js`, as ONE point every copy passes through, and it RETURNS the element.** The plan put the swap in `dressCopy` as a `replaceWith`. Stage 0 measured why that cannot work: all eleven sites that clone an element do reach `dressCopy`, but some enter it with a PARENTLESS copy (an atom that is a direct child of a cut block through `fragments.js`' `deep`, the hollow shells and chain elements through `register`, and any top-level block that is itself the claimed element), where `replaceWith` is a silent no-op, and the studio's schema writes exactly that shape. So the swap is decided where the copy is made, and the caller uses what comes back:

- `copyOf(source, into)` — a deep copy, registered; a presented source is not cloned at all, its presenter's element is returned. Called by `root.js` (the running element's per-page copy, the composed or fixed-holding block, the top-level fixed box), `reads.js` (the block a `target-counter()` read is taken in) and `fragments.js` (`cloneInterval`'s whole block and its `deep` subtrees).
- `shellOf(source)` — a childless copy, registered; `fragments.js`' `hollowOf` and `build`.
- `measuringCopyOf(source)` — a deep copy that is dressed and not registered, for the Compositor's two passes (`compose-dom.js`), with `dressWords` swapping the descendants.
- `mapCloneToSource`, the walk under a root copy, replaces a presented child by the presenter's element in the same index, so the lockstep with the source's children holds, and does not descend into it: the presenter's children are the presenter's, never the source's.

Nothing in `src/` or `seam/` copies an element any other way (stage 0 swept for `cloneNode`, `outerHTML` and `importNode`), and `fragments.js`' remaining `cloneNode(false)` copies a text or comment node.

**Every copy is presented, without exception**, the Compositor's measuring copies and the hollow shells included. A measurement must see the box the page will show, or the cut is made on one size and drawn at another; the pin cuts a document whose plates are 60 px by the author's CSS and 120 px by the presenter's and finds the Ledger of a document whose CSS says 120, in both modes, and the composed run reads a chip's width from the measuring copy. A hollow shell of a matched element is the presenter's element, concealed by the words the caller writes, so a concealed `<object>` never exists as a copy. The element carries the `data-beltype` words its source earned (the `has:` answers) exactly as any copy does, and `sourceOf` answers the source.

**A presenter's element answers `isAtom` as its source does.** `isAtom` named a replaced element by its own tag, and a `div` standing in for an `<object>` is not one; it now reads the tag and namespace through `SOURCE_OF`, as it already read the display through `sourceStyle`. For every other copy the source has the same tag and namespace, so nothing moves; for a presenter's element the procession still stops at the atom.

**A block that holds a presented element is always shown through a copy.** In `root.js`'s presentation, `composition || ctx.holdsFixed(source)` gains `|| ctx.holdsPresented(source)` (asked once per source, cached like the fixed box). Otherwise the whole block on one page would be assigned as the ORIGINAL, and the original's `<object>` would be on the page: stage 0 measured that a shown `<object>` starts the viewer and a parked one costs nothing. So the original stays parked (*an unplaced original is parked, not unassigned*), and the cost is the one a composed block already pays: a copy matches `:nth-child` and `:last-child` against its position among the slot's siblings.

**A registration after the first run is a condition, like any other.** The seam's conditions key gains the number of registered presenters, so the next call is a whole run (`describeConditions` says "a presenter was registered"), nothing a presenter touched is reused, and the composition cache is cleared. A run stopped at a page goes on under the presenters it began with; its built pages keep the elements they were built with. Registration is meant to precede the first run, and a host that registers late pays a whole run.

**Refused: the swap inside `dressCopy`.** Measured not to work (above). **Refused: a mark on the source** — a word in `data-beltype`, or a new attribute. The attribute is reserved to belt, engine and host; the source keeps the platform's markup (the round's ruling), and the selector is the author's own `type`. **Refused: presenting only the copies a page shows.** The measuring copies would be the object, and the cut would be made on the wrong box. **Refused: copying the source's attributes onto the presenter's element.** The element is the host's; a presenter that wants the source's `id`, class or size reads them from the source it is handed.

## Consequences

- **`make` runs often**: for every copy of every matching element, each page that shows one, each hollow shell, each of the two passes of the Compositor and each read. It must be cheap and synchronous and must not start work per call; an element that costs something defers it to `connectedCallback` and draws from a cache.
- **The presenter's element holds no text**: an atom's content is not in the word space, and the presenter's children are not walked. Text in it would be words the document does not hold.
- **The author's CSS addresses the source, not the presenter.** A rule written for `object.plate` does not match a `div` or a custom element. The presenter sizes itself, from the source it is handed or from a cache, and a host that registers a presenter owns the box it makes. Stage 2's element (`<beltype-facsimile>`) takes its size from the source's PDF page at intake, the rule images follow (*images are awaited at intake*).
- **A block that holds a presented element is shown through a copy**, and a document of such blocks gives up the zero-copy presentation for those blocks. The decision is per source block, not per document.
- **Chromium's print of an `<object>` with a `type` it does not render and a `data` that is not there prints its own plug-in text** (found by `cases/122-the-atom-that-is-a-page`'s first draft): the browser's treatment of an unsupported `object` is not an empty box. Case 110 uses an empty `object`.
- **The pre-intake fetch is not solved here**: before Cicero parks the original, the document's own load fetches it (stage 0, part B), and the cure is a static hide rule in the seam's head, which stage 2 measures before relying on it. **Amended 2026-10-14 (stage 2):** the rule is `object[type="application/pdf"]:not(beltype-root *) { display: none }` in the head's provision sheet (`seam/index.js`), measured to leave zero requests and zero viewer frames before the first cut and the first run's Ledger unchanged — provided the presenter is registered before the first measure, because the measuring copies live in `#__beltype-measure`, outside the root, and a copy that is still a typed `<object>` is matched and measured as `display: none`. The client therefore loads the facsimile at intake, awaited, and a document that embeds a PDF and cannot load it refuses the run by name. The presenter itself is `seam/facsimile.js` and is an `<object is="beltype-facsimile">` (the author's CSS addresses `object`), which copies the source's attributes except `data` and `type`; it sets the `is` ATTRIBUTE itself, since `createElement(…, { is })` sets none.
- **Amended 2026-10-28 (a facsimile's copy holds its box off screen):** the presenter's element holds no child until it is drawn, and then one `<canvas>`. An `<object>` with a child and no `data` renders its fallback content, decided at its first layout, and on a `content-visibility: auto` page (*a page is contained*) a read from script lays the page out for the length of the read and loses that decision, leaving the copy with no box; measured, the same copy with no child keeps its box on every read. The pin is `packages/essay/test/facsimile-off-screen.test.js`; CHANGELOG 2026-10-28.
- **Owed to the checklist**: nothing; the capability is a host's hook, not a CSS Paged Media capability.

The pins: `packages/essay/test/presenters.test.js` (every path a copy is made by; the cuts on the presenter's box; the late registration), and `cases/122-the-atom-that-is-a-page` (pagination needs nothing for an atom the size of a page, written green).
