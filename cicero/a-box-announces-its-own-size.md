# A box announces its own size

**Status: Decided 2026-10-21, Executed 2026-10-21.** A design round with Egildo, 2026-10-21, after the showcase document found faults a reload fixed and nothing else could. The rim ([*late truth is an edit*](late-truth-is-an-edit.md)) hears three named causes; this record adds the one that needs no name. The round that builds it is `.claude/plans/a-box-announces-its-own-size/plan.md`. The name and the refusal of a host switch are Egildo's rulings of the same day.

## Context

The rim listens on the top-level boxes for an image loading inside one, a custom element being defined, and a face arriving, and its header says in so many words that nothing is observed by size. Every other cause of a changed geometry, a sheet a script toggles, a component rendering after upgrade, a formula library settling late, a `<details>` opened, a chart drawn by a timer, leaves a page cut on an extent that is no longer true, and only a reload corrects it. The showcase (the studio's `demos/showcase`, 2026-10-21) met several of these in one document.

Egildo's proposal: the components should know when a new overflow happened because the rendered DOM changed, redo only the measuring, and return a position to the ledger, which invalidates what follows; an on-demand alarm is the most precise and the most economical way, whatever the CSS does. The ledger already has the verb: `run({ resumeAt })` restarts one page before an entry and stops where the next entry's address comes out equal ([*the run resumes from an entry*](the-run-resumes-from-an-entry.md)). What is missing is the ear.

## Decision

**A top-level box announces its own size, and a size the account did not expect is an edit at that box.** Four rulings.

1. **The unit is the box, not the page.** A `ResizeObserver` on each top-level original reports its border box; a box divided across pages is still one original, clipped by the flow, so its own height is a clean reading of its whole extent. The signal is the rim's fourth kind, `size`, with the boxes that changed, and its default action is the one the rim already has: one `run({ resumeAt })` per box, earliest in document order first, convergence stopping each. A host takes the pace by cancelling the same event it cancels today.
2. **The ear never measures.** An observation on the presented page is a trigger and nothing else; the resume re-feeds the Gauge in the measure context, where cuts are decided. The two-clock rule stands.
3. **Hear always, read a box only while it is presented, compare against the last run's measurement, act between runs.** The observer is never paused: a change that lands after the Gauge read a box and before the run ends is exactly the one a paused ear would miss. A signal heard during a run is held, as the rim holds every signal, and judged when the run ends. The gate is one comparison: the observed border-box height against the height the last run measured for that box, within the engine's own tolerance of a quarter pixel; equal is not news, and the engine's own writes produce exactly what the account records, so they pass through the same gate and are filtered by it. A box assigned to the parking slot renders nothing and reads zero, so a box is read only while it is slotted into a built page; parked is not changed.
4. **Three resumes per box per epoch**, then the last layout stands and the console names the box, the reads' own posture for a value that keeps moving its line.

**What this is not.** Size catches an extent that changed. A paragraph that reflows to the same number of lines has the same height and a different cut, since a cut is a word address at a line boundary. So the alarm is a floor under every unknown cause and not a proof, and it does not replace the reads' line check, which measures lines; delivery keeps its own check and its own resume ([*delivery resumes from the moved page*](delivery-resumes-from-the-moved-page.md)).

**Refused.** Observing the page hosts (a page's size never changes; the pages hold what changed). A flag on the engine's own writes to tell them from foreign ones (the equal-extent gate tells them apart with no bookkeeping, and a flag would miss a foreign change that lands during an engine write). Pausing the observer during a run (ruled out above). Observing by `MutationObserver` (a mutation is not a geometry; most mutations change no extent and the ones that matter are already in the box's size). A host switch to turn the ear off for a document whose script resizes boxes by design (ruled 2026-10-21): the budget is the switch, three resumes per box and then silence, and a document for which that is too many is the case that would add a knob, not a reason to add one in advance.

## Predictions, frozen on write

1. **A sheet toggled after the first run re-cuts from the first box it changes.** A case or a browser-backed test: a document of several pages, a `<style>` appended after `beltype:ready` that doubles a paragraph's line height on page three; the pages before three keep their entries byte-equal, page three and after are re-cut, and the account equals the one a fresh run gives on the same document. Break: a page before three re-cut, or the two accounts differ.
2. **A change inside a continuation's original resumes from the original's page**, measured on a divided block whose inner element grows by script.
3. **Windowing sounds no alarm.** Scrolling the manual (123 pages) end to end under the editing tools issues zero resumes from the `size` kind, measured by counting the rim's signals. Break: one.
4. **The engine's own runs sound no alarm.** A whole run, a `run({ until })` paced run and an edit's `run({ resumeAt })` each issue zero `size` resumes after their own presentation; counted on case 82 and on the manual.
5. **Every standing battery record reproduces**, and the editing-tools suite is green.
6. **The gate's cost is negligible**: observing the manual's top-level boxes and judging one batch of observations is under 2 ms, measured.
7. **Expected unmeasurable**: a reflow that keeps a box's height and moves its cut passes the gate unheard; stated as the limit above, no case can show the alarm catching it.

## Consequences

- **Displaced**: the rim's sentence "nothing is observed by size"; the reload as the only remedy for a late sheet or a late component.
- **Owed**: the `size` kind in `seam/rim.js` with the two predicates (presented, within tolerance); a table of the last run's measured border-box height per top-level box, kept where the warm start lives, filled by the driver from the Gauge's report; the per-box resume budget; the checklist's frontier row; the rim's and the client's headers; a record of what each foreign cause costs once the alarm is in (a sheet, a component, a details element).
- **Not owed here**: hearing a clone's own change (a clone is the engine's construction); hearing reflow at equal height; anything about the measure context.
- **Where the content lives**: the mechanism in `seam/rim.js` and `seam/client.js`, the table beside the warm start, the status in the checklist, the story in the CHANGELOG under its date.

## Verdict

Built 2026-10-21 on `round/a-box-announces-its-own-size`; the proof is `packages/essay/test/size.test.js` (seven tests) and the hearing probe, P40 (`packages/essay/probes/hears.js`, its table in `probes/README.md`), the battery 25 of 26 gates in 5.5 min against `0a6d23a`, every standing record reproduced (the six differential tallies, the three view gates, acceptance in both modes, the cases, conservation, the fourteen probe gates and the browser-backed suite), the one red gate the engine's DOM-free suite on this record's link to *delivery resumes from the moved page*, a record still on its own branch; so the pin was not rewritten.

1. **A sheet toggled after the run re-cuts from the box it changes — held in its result, and the mechanism is a whole run.** On a 13-page document a `<style>` doubling the line height of the first paragraph drawn on page three is one `size` signal naming that box and one answer; the account after equals a fresh run's on the same document, and pages one and two are byte-equal. The answer is `run({ resumeAt })`, and the resume is refused because a sheet is a run condition (*the run resumes from an entry*, Decision one: *the document wore 1 stylesheet and now wears 2*), so the run is whole and pages one and two are cut again to the same bytes. The same change written as an inline style by a script is not a condition and resumes, `{ from: 3, to: 13, converged: true }`, to a fresh run's account. The record did not see the conditions key.
2. **A change inside a continuation's original resumes from the original's page — broke.** A `<div>` of fourteen paragraphs divided from page one, one paragraph grown by 40 px by script: zero signals. Since *the first fragment is constructed* (2026-09-15) a divided block is drawn wholly through its fragments and its original is parked, so the Decision's premise, *a box divided across pages is still one original, clipped by the flow*, was already false when it was written; the original reads zero and is never heard. The copies the reader sees did not change either (the change reached the original only). The control, the same growth in an undivided block, is one signal and one resume. Hearing a divided box is a design question this record does not answer. Answered by [*a fragment announces its own size*](a-fragment-announces-its-own-size.md) (2026-10-22): the rim observes the pieces a page draws a divided block through, and the same growth written on the paragraph and on its drawn copy is one signal naming the `<div>` and a resume from the piece's page, in both modes.
3. **Windowing sounds no alarm — held.** The manual under the editing tools, 301 pages in the pane, cut (first view, then idle slices) and scrolled end to end: zero `size` signals. It has 25 top-level boxes and draws 7 as themselves, the rest chapter sections divided across pages, and the idle slices had built every page before the scroll; windowing proper is pinned by `size.test.js` on a 137-page document of 400 top-level paragraphs, 6 pages built at first, scrolled end to end: zero.
4. **The engine's own runs sound no alarm — held, after one fix.** Case 82 as written (one `<section>`, never drawn as itself) and with the section unwrapped (5 of 8 boxes drawn, each at its measured height to the pixel): a whole run, a run stopped at page one and carried on, and an edit's resume, zero signals in all six; the manual's edit, patched and resumed by the editing tools (`{ from: 1, to: 1, kept: 300 }`), zero. The first reading heard one signal on the unwrapped paced run: a page a stopped run shows is skipped by the browser for one frame (`content-visibility: auto` before its first relevance), its originals read zero, and zero was judged against the measured 80 px. Zero is now what a box no page renders reads, parked or skipped, and is not news.
5. **Every standing battery record reproduces, and the editing-tools suite is green — held, with the one red gate the record caused itself.** 25 of 26 gates in 5.5 min against `0a6d23a`, every standing record reproduced (the six differential tallies, the three view gates, acceptance in both modes, the cases, conservation, the fourteen probe gates and the browser-backed suite), the one red gate the engine's DOM-free suite on this record's link to *delivery resumes from the moved page*, a record still on its own branch; so the pin was not rewritten. The first complete run stalled in the conservation gate for 25 minutes with the browser idle (the gate alone took 75 s, and the next run passed it); the second was red on the browser-backed suite once, a `size` heard beside the element and the face the rim test brings, and the ear now asks again whether a run or an answer began before it judges (the essay suite twice green after it). The editing tools: 105 of 105.
6. **The gate's cost is negligible — held.** The manual's 25 top-level boxes: observing them under 0.1 ms, the rim's callback at most 0.2 ms, its judgement at most 0.1 ms. The first reading took 3.5 ms to judge 2 boxes, in the task the presentation ended in (`assignedSlot` recomputing the slot assignment the run left); the judgement now waits for the frame after the runs and the task after it. Four hundred top-level boxes: observing them 0.2 to 0.9 ms over two readings, the callback at most 0.2 ms, the judgement at most 0.3 ms.
7. **A reflow that keeps a box's height and moves its cut passes unheard — stated, unmeasured, as expected.**

**What the record did not foresee.** The conditions key turns every size a stylesheet causes into a whole run (prediction 1). The fragments make the ear deaf to every divided block and to the whole composed mode, which in a BelType document is most of the top-level boxes (prediction 2). A box on a page far from the reader is heard only when the page comes near, since the browser skips the page's content and it reads zero (the hearing probe, P40e: a growth on page 101 heard on `reveal`, resumed from page 101). A box shrunk to zero by script is not heard. The rim's cancel tests had to cancel the size their host let stand: a host that cancels a named signal and lets the change stand is told again by the size. The editing tools' resumes are not doubled: their `patch` and `run()` share a task, and the client counts a call as under way from the moment it is made.
