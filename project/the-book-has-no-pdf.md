## Decision

**The book is a BelType document built by the released CLI, site engine only — and it has no PDF, deliberately.**

The responsive site is the published face. The proofs stay standards-only HTML put to the engine. And the print story is reserved entire for Cicero through BelType's engine seam, where the book becomes the seam's first customer — which is the whole reason the obvious thing, exporting the book about pagination as a paginated document, is refused here. **Adding a PDF path to the book is not a small convenience; it spends the demonstration this book exists to set up.**

Every chapter closes on a seeded, regenerable proof. One chapter, the engine room, is licensed technical.

**The arc:** seven parts, fifteen chapters, the geometry chapter joining the general theory and the monolith moved early.

**Write beside, not over.** The old book is mined hard and retired only when the new one stands.
