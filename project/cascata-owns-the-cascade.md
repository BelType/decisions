# Cascata owns the cascade

**Status: Decided 2026-09-02.** Part of the BelType-on-Cascata round, alongside [a venue is a schema](a-venue-is-a-schema.md), [run options are flags](run-options-are-flags.md), [the keyscope is not the cascade](the-keyscope-is-not-the-cascade.md) and [the MVP cut](the-mvp-cut.md).

## Context

`packages/core/src/config-schema.js` was BelType's own constitution for configuration: a key manifest declaring type, territory, cascade behaviour and space for every key, an ad hoc JSON-Schema subset for `schema:` (values-only, branching keywords refused by name, unknown keywords erroring), a `moldRef` type for `spec:` with its own displacement rule, and a `checkTerritory` pass enforced as a build-failing error because a key spoken where it cannot be read used to merge and then silently never be read — `CLAUDE.md`'s own gotchas name the wound directly: a numbered PDF that could not be re-checked after it shipped, a `theme` switch that failed the framework-creep test, a mold catalog built and cut the same day. Every one of those rules was hand-built because nothing else existed to build on. `TABLET.md`'s "Trust the standard" names exactly this situation: a proposal that starts to look like "and now we build our own version of X" is the sign to look harder for the X that already exists. Cascata is that X — a schema-governed cascading configuration library with the property `config-schema.js` was reaching for by hand and never quite closing: monotonicity, proved rather than merely hoped, with provenance recorded at every node and an error contract that names the layer, the line, and the rule broken.

## Decision

**`config-loader.js` and `config-schema.js` are deleted. Cascata's `load()`, embedded through its Node host, answers every question the manifest used to answer by hand.**

The isomorphism is close enough that it is worth naming plainly, because it is the argument for the move rather than decoration on it. BelType's `TERRITORIES` table — who may speak a key, enforced as an error — is Cascata's `seal`/`final`/`authority` (Article III): a schema closes its own shape and can freeze a key against every further declaration, with the same "errors, never warnings" posture `config-schema.js` had reasoned to independently. BelType's molds — a `spec:` naming a directory that is a DOCTYPE, carrying both what a document comes *with* and what it must *satisfy*, displacing whole rather than merging — is Cascata's `$adopts` pedigree, which formalizes exactly that unification (a schema is simultaneously data and contract) with a proof obligation BelType never had: subsumption. BelType's `requires:`, hand-carved as "BelType's word, not sugar for `schema.required`" because a file's own demands had to *add* to whatever contract governs rather than replace it, is precisely how Cascata's `required` keyword behaves under its monotonicity table for every key, natively — "Add" and never "Remove". BelType's `params` deref (`deref: true`, one hop, no globs, "a string is data about a file, never a second deref") is, keyword for keyword, Cascata's delegation razor: a `resource` type says a string *names* a file, `delegate: allow` says a string *loads* one, and the two are never the same key. And a mold's refusal to fetch — "a build never fetches," marked `⟲ reversible` in `CLAUDE.md` because `TABLET.md` retired the doctrine in favour of trust-through-verification — is answered structurally rather than by a standing refusal: Cascata's Host Boundary gates remote resolution behind a host that must supply it *and* a user who must opt in, with a `$pin` content hash making the fetched artifact checkable. That is what "trust through verification, not refusal" asked for, built by someone who was not solving BelType's problem and arrived at BelType's own conclusion anyway.

What does **not** move is the anchoring math — fs-space against a declaring config's directory, url-space against its URL origin, root-absolute rewriting at the seam — because that is a question about what BelType *serves*, not about what a value *is*, and Cascata's `resource` type marks a value as such a reference without knowing or needing to know what a browser will do with it. `packages/core/src/linker.js` keeps that job unchanged; a different question, answered elsewhere already.

What BelType keeps on its own side of the seam is two things, deliberately small. **The venue probe** — finding `beltype.config.yaml` beside a target, walking up when it is not there — survives because Cascata's Host Boundary draws exactly this line: the host supplies bytes, never meaning; it answers *what is at this location*, never *is this allowed*. Locating the venue is supply; BelType's Node host answers it precisely as it answers every other `readText`. **A refusal list**, applied once over the projected value rather than per-rung, closes the one door Cascata's own sealing cannot reach — frontmatter has to stay unsealed for reasons [run options are flags](run-options-are-flags.md) states in full; this entry only notes that the list exists and is BelType's, not Cascata's, because it polices words Cascata has no way to know are reserved.

## Consequences

The key manifest's derived maps (`FS_PATH_KEYS`, `URL_REF_KEYS`, `APPEND_KEYS`, `DEREF_KEYS`), `checkTerritory`, `validateConfig`, the hand-rolled JSON-Schema subset (`schemaShapeProblems`, `valueProblems`), and the mold expansion machinery in `config-loader.js` are gone entire — not ported, not shadowed. What a venue writes to reach the same behaviour changes shape; [a venue is a schema](a-venue-is-a-schema.md) is that record. The territory apparatus's *enforcement* posture — errors, never warnings, because an artifact cannot be re-checked after it ships — survives, but as Cascata's own error contract rather than BelType's `checkTerritory`; nothing about "a key spoken where it cannot be read merges silently" reopens, because Cascata refuses before merge exists to be silent about. `include.js`'s keyscope — the one thing that resembles a cascade and is not one — is untouched by this entry on purpose; [the keyscope is not the cascade](the-keyscope-is-not-the-cascade.md) says why it stays BelType's.
